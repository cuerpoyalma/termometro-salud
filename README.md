# Termómetro de Salud

Sitio web estático (HTML, CSS y JavaScript, sin build) publicado en Vercel.

- `index.html`, `styles.css`, `app.js`: el sitio.
- `assets/`: informes descargables (DOCX y PDF).
- `vercel.json`: cabeceras HTTP (incluye `noindex` mientras está en preview).

## Publicar
Importar el repo en Vercel con preset "Other" (sin comando de build, directorio raíz `/`) y conectar el dominio desde Settings → Domains.
